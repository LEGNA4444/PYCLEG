Especificaciones del servicio

Alcance del servicio

Se entregan sitios estáticos, optimizados para rendimiento y accesibilidad. El alcance exacto se define en la propuesta y puede incluir número de secciones, funcionalidades JavaScript y estilos CSS según lo acordado con el cliente.

Entregables

  • Archivos HTML/CSS/JS listos para desplegar en GitHub Pages o servidor estático.
  • Instrucciones básicas para publicar y actualizar el sitio.
  • Notas sobre mantenimiento y recomendaciones opcionales.

Limitaciones

No se incluyen bases de datos ni servicios de backend a menos que se especifique explícitamente.
